# PDFI4 Output-Only Guidance Accounting Checkpoint

## Evidence And Boundary

A retained small-form finish request has earlier output-only scoped accounting and advisory uncertainty,
but no accepted, acknowledged, or scoped field IDs in any pass. A later private interpretation cannot
classify that same utterance as guidance because all scoped spans are currently immutable. The job stays
pending even though no field instruction was applied. Absence of field IDs alone does not prove that the
utterance contains no facts, so clearing the input from metadata would be unsafe.

## Invariants And Chosen Change

Keep interpretation in the existing protected, tools-disabled call and mutation in native atomic apply.
Permit reclassification only when the entire original utterance is explicitly covered by current exact
non-data literals, the current intent is guidance, and there are no current proposals, findings, or output
instruction. Native eligibility additionally excludes all accepted/acknowledged/scoped field history,
positive accounted evidence, and native invalid/conflicting/unsupported/unresolved findings.

Only output-only scoped bookkeeping may become non-data. Preserve selected output scope, deferred fields,
ledger, review, revisions, and approval. The existing advisory-resolution rule remains window-bound;
unrelated findings still block completion. Exact replay and restart must preserve the result.

Expose eligibility solely as ephemeral metadata on the existing private accounted-literal view. Do not
add persisted fields, public arguments, new storage, increased budgets, guessed classifications, or a
discard-input operation. Old records remain readable; no store migration or rollback incompatibility
is introduced.

## Alternatives And Validation

Automatic clearing based on empty scoped IDs would lose potentially unhandled facts. Resetting jobs or
restoring snapshots bypasses the operator's transaction. Replaying per-field dispositions manufactures
instructions. A separate recovery state machine duplicates existing accounting. The bounded same-input
reclassification is the smallest coherent repair.

Add a failing native regression for output-only history, restart and replay; negative cases for partial
coverage, facts, field dispositions, native blockers, and current scope changes; private encoder coverage;
then focused/race tests, formatting/lint, exact-head CI/review/approval, merged deployment, and same-job
qualification. Cross-message invalid-value correction is a separate prerequisite and is not solved here.
