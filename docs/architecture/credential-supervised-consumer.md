# Supervised Credential Browser Consumer

## Status and ordering

The private `browserworker.StartSupervised` entry composes the fixed Root
resource allocation, actual signed `LoginLease`, enforcing HTTPS proxy and
private Go/Node channel. It retrieves no secret during startup, exposes no
agent tool, and accepts no executable, profile, listener, URL or command.
The credential CLI does not invoke it. Unsupported systems deny.

Trusted startup must separately qualify the protected Linux host/VM, canonical
disjoint roles, fixed Root service and authentic immutable browser runtime.
The constructor requires actual approval and trusted callbacks for current
complete scope and independent submit policy. It denies withdrawn authority
before allocation. Every operation still checks the original lease generation,
principal, account, policy revision and live origin. No grant is renewed.

The broker adopts the allocation's listener and control stream, closes the
received originals, and attaches the enforcing proxy before requesting start.
The first listener `Accept` proves that proxy serving reached its owned
listener; starting a goroutine alone does not. Failed startup or canceled
setup denies start.

Root executes only its existing fixed program. The broker configures the
private channel with `/bin/chromium` from the admitted runtime image, the
proxy endpoint/pin and the lease's immutable flow/remaining lifetime. The
existing configuration acknowledgment requires protected browser startup and
the sandbox witness before any later login retrieval. An allocation or
initial-exec acknowledgment does not qualify Chromium. No SDK client or token
is initialized here.

## Ownership and retirement

The constructor retains its original caller lifetime with the Root allocation.
This must be a qualified caller/session lifetime, rather than an incidental
request timeout or a model-selected identity. Root's independent 20-hour
resource ceiling supplies no approval authority.

The constructor owns every adopted copy, including partial adoption on failure.
Loss of Root allocation authority or original caller cancellation closes the
proxy, listener and control stream and withdraws the allocation. A canceled
context cannot be replaced to revive it.

Grant withdrawal immediately removes proxy/network and private operation
authority. The bounded channel close protocol can finish while the original
resource connection remains alive. Its stop callback closes adopted sockets
before requesting Root's verified whole-forest retirement. Cleanup is attempted
once; no login or retirement is replayed.

A successful normal close requires both the private close acknowledgment and
Root's verified retirement reply. Lost resource/caller authority supplies no
such proof and permanently quarantines the session. Root independently
verifies bounded cleanup before another allocation. A known retired session
returns a fixed denial before any new provider call.

## Qualification and remaining work

Composition fixtures use actual CA1 authority and Linux kernel endpoint adoption
with synthetic Root/proxy/worker peers. They exercise normal scoped login,
partial adoption, proxy/start/configuration failure, original cancellation,
server loss and grant revocation. Device/inode reference counts verify adopted
copies are absent before retirement and after withdrawal. Public startup
requires the actual signed lease and production implementations; synthetic
factories remain package-private.

These tests do not qualify real Root IPC, TLS or Chromium; their existing
separate OS/browser fixtures retain those responsibilities. End-to-end
qualification still requires an authentic runtime on the protected Mac VM,
physical Android enrollment, protected 1Password provisioning and an
individually admitted account. No real vault material is used here.

Broker session registration, remote typed intents and operator handoff remain
later composition. A private session is not a model result, cookie export or
ordinary browser handle. Any opaque reference must retain its complete
principal/account/revision and original grant binding.
