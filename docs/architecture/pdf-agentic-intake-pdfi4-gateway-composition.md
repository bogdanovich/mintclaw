the same unavailable-model semantics; unreadable form state fails closed. With a healthy store and no active form,
normal chat is not intercepted. A disabled document tool opens no form store. Isolated coding/read-only composition
still has its own existing local-artifact surface, not gateway form intake.

editable draft capability and truthful hybrid refusal. It does not contain document or field-name-specific mapping.
